# Android WebDAV 双端补齐

## 目标与边界

Android 独立访问用户配置的 WebDAV，兼容当前 Windows `Titanhub/sync/v1/devices/` 快照。同步收藏与最近位置，保留来源/类型/作品复合身份，不同步凭据、插件或媒体文件。不连接用户真实网盘做开发验收。

## 分工

- Codex：范围收敛、集成、交叉运行时验收与打包。
- dsh：DAV传输与传输回归；原大任务因探索过久收窄。
- Claude：桌面/手机协议审查、设置UI、安全配置与发布执行器。
- Codex补充：数据库同步状态与本地事务、进度单位转换、集成修正与跨运行时验收。
- agy：参考项目双端机制调查与设置交互检查。

## 实施顺序

1. 对比 Kazumi/Venera/Mangayomi 与现有桌面代码，确认格式和触发机制。
2. 持久保存设备身份、逻辑时钟、记录和墓碑、不可变待发快照；与本地修改同事务落盘。
3. 直连 DAV，验证目录/XML/地址范围，限制请求和响应大小，禁跨源重定向；不在日志暴露密码。
4. 补设置入口：地址、用户名、密码、安全保存、连接测试、手动双向同步、清晰的忙碌/错误/完成状态。
5. 回归正常同步、离线删除、并发编辑、失败/重试、异常快照拒绝、跨类型隔离和现有阅读恢复。
6. 同一个临时 DAV 中运行桌面和手机实现，验证双方实际写入/读取；Android 16 安装检查后更新测试APK。
