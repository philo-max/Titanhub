# Titanhub 1.1.0 Android 独立 APK

用户目标：手机独立使用，无需电脑运行；继续使用现有 Flutter 原生客户端。

状态：2026-10-29首个本地通用测试APK完成；已验证Android16/16KB实际release界面的搜索、漫画阅读与重启后资料保留。当前只内置Bangumi资料、MangaDex漫画，不声称桌面全部来源或真实视频/小说来源已移植。

## 方案与取舍

1. 推荐沿用 Flutter + 本地来源引擎/SQLite，补 Android 工程、默认本地模式和触屏流程；复用现有代码，来源能力须逐项验证，不能直接承诺桌面全部来源兼容。
2. WebView 包装网页需要手机上额外运行 Node 或连接电脑，与本次独立使用目标不符。
3. 全量重写 Android 原生客户端工作量大，本轮没有必要。

## 首批开发范围

- Android 工程、1.1.0 版本、已有娘化图标、网络权限、打包与兼容性检查。
- 本地来源作为默认入口，移除默认等待桌面接口及 Mock 入口；来源能力不足给真实提示，保留明确选择的远端能力，不自动连接电脑。
- 真实可用来源的搜索、详情、章节、播放/阅读，补来源选择和必要安装管理；先验证支持范围，再标记可用。
- 收藏和进度按来源/作品隔离，在本机保存和恢复；适配小屏、安全区域、返回及后台生命周期。
- 原有同步协议保留；桌面账号/云同步尚未对齐部分不做成必选流程，不存明文凭据。
- 首轮产出可本地安装验收的 APK；测试版签名与正式长期升级签名需明确区分，私钥不入库。

## 分工与验收

dsh负责明确模块实现；Codex负责环境、集成及独立验收；Claude仅处理复杂阻塞和关键审查。开发前确认上述多文件范围；保留工作区现有桌面修复。

验收包括 Dart/Flutter 静态分析与测试、真实Android构建、包内版本/权限/架构/签名检查、模拟器启动与本地收藏/进度及至少一条真实支持来源的内容链路；未实测功能明确记录，不用Mock成功替代真实来源。

## 实施与验证结果

Android工程、Flutter3.47.8/JDK17、真实Drift生成及本地模式均已落地；APK为1.1.0+1、min24/target36、ARM64/ARMv7/x86_64通用包，当前内部测试签名。80项单元及Android14原生14项通过；Android16 debug自动化调试连接受限未计通过，另已实际操作release包完成真实内容链路、收藏与第4页恢复、两种屏幕布局检查。完整结果见同日实施计划与progress.md。
